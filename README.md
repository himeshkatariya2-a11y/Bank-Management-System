🏦 Bank Management System (C++)

📌 About the Project

The Bank Management System is a console-based application developed using C++. It helps users perform basic banking operations through a simple menu-driven interface.

✨ Features

- Create a new bank account
- Account details management
- Check account information
- Deposit money
- Withdraw money
- Basic banking operations

🛠️ Technologies Used

- Programming Language: C++
- Concepts: Variables, Conditional Statements, Loops, Functions, and Basic Programming Logic

▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code or any C++ IDE.
3. Compile the ".cpp" file.
4. Run the program.

🎯 Project Objective

The main objective of this project is to improve C++ programming skills by implementing basic banking operations and understanding real-world banking logic.
